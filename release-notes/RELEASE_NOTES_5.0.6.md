# Release Notes 5.0.6

<en-GB>
- Upgraded to React Native 0.77.2 with full 16 KB memory page size support.
- Updated target SDK to Android 16 (API Level 36).
- Improved background audio playback and timing accuracy.
- Resolved camera freeze issues during walk prompts.
- Refined walk detail screen layout.
- Reduced download size and improved stability for Android 15 and 16.
</en-GB>
